## 怎么用（自己让 AI 读）

1. 打开任意 TTS（剪映文本朗读 / 讯飞 / ElevenLabs / Azure）。
2. **一段一个文件**地读，得到 9 段音频。
3. 剪映/Pr 导入 `phyxexp_demo.mp4`（无音轨）。
4. 把 9 段音频依次放到：**0:00 / 0:15 / 0:25 / 0:55 / 1:15 / 1:55 / 2:35 / 3:15 / 3:45**。
5. 导出。

## 对齐要点

- 只对齐**开始时间**；每段旁白都短于场景时长（见上表），自然结束即可。
- 若某段 TTS 偏慢、超时：语速调到 1.1–1.2 倍，或删掉最后一句。
- 数字念法：9.85 = 九点八五；±0.04 = 加减零点零四；k=2 = k 等于二。
- 段间留 1–2 秒空白。
