# 高级 PPT 制作流程（内容不变，去 AI 味，与视频对齐）

## 0. 先说清楚：为什么上一版有「AI 味」

1. **版式雷同**：每页都是「标题条 + 一排圆角卡片」，翻页像复制粘贴。
2. **信息太满**：卡片里塞小字，一页讲三件事，观众不知道看哪。
3. **配色无取舍**：蓝+橙是默认科技风，没有主次。
4. **没有实拍/截图**：全是文字块，缺「真实感」。
5. **没有节奏**：每页一样「吵」，没有安静页衬托重点。

高级感的核心不是「加装饰」，而是**做减法 + 建立秩序**。

---

## 1. 六阶段流程

### 阶段 0 · 定约束（10 分钟）
- 受众：评委（懂技术、没耐心）；场景：投影/线上；时长：与视频一致（3–4 分钟）。
- 比例 16:9，分辨率 1920×1080。

### 阶段 1 · 先文字，后视觉（最重要）
- 写**一句话主张**：`让实验数据处理值得信任`。
- 每页标题写成**结论**，不是目录词：
  - 不要「痛点分析」→ 要「学生把时间花在算上，而不是想上」
  - 不要「方案介绍」→ 要「不是让 AI 更会算，而是不让它算」
- 每页只留**一个信息点**。

### 阶段 2 · 定视觉系统（一次性定死，后面不改）
- **色**：主色 1 个（深墨蓝 `#14213D` 或近黑 `#111111`）+ 强调色 1 个（电光橙 `#FF6B35`）+ 灰阶 3 档。
- **字**：全篇只用 1 个中文无衬线（思源黑体），数字用等宽字体（JetBrains Mono / Inter）；标题 ≥ 40pt，正文 ≥ 18pt。
- **网格**：12 列，左右边距 0.8"，所有元素对齐网格。
- **留白**：每页至少 40% 空白。

### 阶段 3 · 选页原型（每页只用一种）
- **封面**：全屏纯色/大图 + 一句话。
- **金句页**：纯色底 + 超大一句话（用来制造节奏）。
- **对比页**：左右两栏色块 + 数字，**不用表格**。
- **数据页**：一个大数字 + 一行注。
- **架构页**：极简线框 + 箭头，不堆文字。

### 阶段 4 · 填内容
- 能用数字/截图，就不用段落。
- 正文 ≤ 3 行；一页一个观点。
- 删掉所有「装饰性形状」（多余线条、阴影、图标堆砌）。

### 阶段 5 · 与视频保持风格一致（见第 3 节）
- PPT 和视频是**两个独立作品**，不逐镜头对应；只要求**视觉、术语、数字、主张**统一。

## 2. 视觉规范（可直接照做）

| 项 | 规范 |
|---|---|
| 主色 | `#14213D`（深墨蓝）或 `#111111`（近黑） |
| 强调色 | 只选 1 个：`#FF6B35`（橙）或 `#2EC4B6`（青） |
| 灰阶 | `#FFFFFF` / `#8A8F98` / `#1A1A1A` |
| 字体 | 思源黑体（标题 Bold / 正文 Regular）+ 数字 JetBrains Mono |
| 标题 | 40–56pt，粗体，左对齐 |
| 正文 | 18–22pt，行距 1.3 |
| 网格 | 12 列，边距 0.8" |
| 圆角 | 统一 8px（或干脆不用圆角） |
| 数据 | 大数字 72–96pt + 一行小注 |

> 关键：**全篇只有一种强调色**。别每页换颜色。

---

## 3. PPT 与视频：两种展示，一套风格

PPT 和视频是**两个独立作品**，不需要逐镜头对应；要做的是**风格统一**——提交时看不出是"两个人做的"。

### 3.1 同一套视觉资产
- 同一个主色 + 强调色（视频片头、字幕条、PPT 全用同一组）。
- 同一个字体方案（思源黑体 + 等宽数字）。
- 同一个"作品标识"：角落的 `phyxexp · 第四届开放原子大赛`。
- **视频片头 = PPT 封面同款**（品牌色 + 标题）；**片尾 = PPT 结语页同款金句**。

### 3.2 同一组数字与术语
- 两边的实验名、结果数字、结论措辞**必须一致**。
- 例：都写 `9.85 ± 0.04 Ω（k=2）`，不要 PPT 写 9.849、视频念 9.85。
- 关键词不换：受约束、可溯源、可复现、能交的报告。

### 3.3 同一个主张
- 视频结尾的「约束，本身就是可信度的来源」「创造力是第一生产力」，PPT 结尾用**同一句**。

### 3.4 互补，不重复
- 视频负责"看到它跑起来"（终端、真实输出）；
- PPT 负责"讲清楚为什么"（痛点、方案、对比、意义）。
- 视频演示过的不必在 PPT 里逐帧复述；PPT 讲过的道理，视频也不必再念一遍。

## 4. QA 清单（录完前逐条勾）

- [ ] 每个标题都是「结论/观点」，不是「痛点分析/方案介绍」？
- [ ] 每页是否只有一个信息点？
- [ ] 正文 ≤ 3 行、字号 ≥ 18pt？
- [ ] 所有元素是否对齐同一网格？
- [ ] 全篇是否只用了一个强调色？
- [ ] 是否删掉了所有装饰性形状/阴影？
- [ ] PPT 与视频的主色、术语、数字、结尾主张是否**一致**？（风格统一，不必逐页对应）
- [ ] 投影环境下对比度是否够（浅底深字或深底浅字二选一）？

## 5. 工具与素材

- **做**：Keynote（最容易出高级感，可导出 PPTX）或 PowerPoint；不要用网页生成器一键套模板。
- **图**：Unsplash / Pexels（免费实拍）；实验器材最好**自己拍**，真实感是高级感的来源。
- **字**：思源黑体（开源）、Inter、JetBrains Mono。
- **图标**：Lucide / Tabler（线性图标，统一 1.5px 线宽）。

---

## 6. 一句话总结

> **高级感 = 一个观点 + 一个强调色 + 大量留白 + 真实截图 + 有节奏的安静页。**
> 把「每页都是一排卡片」改成「每页只讲一件事」，AI 味自然就没了。
> 另外：**PPT 和视频是两种展示，但要像同一个作品**——同一套色、同一组数、同一句话。
