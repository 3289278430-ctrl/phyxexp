# phyxexp 参赛作品 · PPT 与视频制作摘要（可直接交给另一个 AI）

## 0. 作品一句话
phyxexp 是一个「受约束的实验数据处理 Skill」：不让 AI 自由算数，而是把计算锁进审查过的白名单工具链，输出带不确定度、误差预算、run_id 溯源的结果。核心主张：**约束 = 可信度**。

## 1. PPT（11 页，Keynote 制作）

【全局】1920×1080；主色 `#14213D`，强调色 `#FF6B35`；思源黑体；标题 40–56pt，正文 18–22pt；12 列网格，边距 0.8"；页脚 `phyxexp · 第四届开放原子大赛`；每页只用一种版式，**不用卡片**。

1. **封面**：phyxexp / 让实验数据处理，值得信任 / 第四届开放原子大赛·图1赛道。
2. **金句**：创造力，才是第一生产力。（全屏深色，白字）
3. **学生困境**：标题「学生把时间花在算上，而不是想上」；左 60% 实验报告实拍，右 40% 三行：算不完 / 算不对 / 算完不知对不对。
4. **免费 AI 不能信**：标题「能算，不等于可信」；一张终端截图，橙框标出 `9.848571428571425`；小字：15 位小数 · 拍脑袋 · 不可复现。
5. **我们的答案（金句）**：不是让 AI 更会算，而是——不让它算。
6. **对学生意味着什么**：四栏 省时间 / 不犯错 / 能复核 / 会分析。
7. **对比**：「一个数 vs 一份能交的报告」；左栏 15 位小数、右栏 `9.85 ± 0.04 Ω（k=2）`。
8. **场景**：学生（贴数据→自动识别→一条命令）/ 教师（run_id + 哈希可查真假）/ 宿主（Claude / ChatGPT / CLI）。
9. **作品形态**：横向流程 `SKILL.md / OpenAPI / CLI` → 受约束编排层 → 十余个白名单工具 → 结果 + run_id。
10. **现在与未来**：现在专注大学物理实验、把可信做扎实；未来衍生场景 / 多个 Skill 合并。
11. **结语**：创造力，才是第一生产力 / phyxexp——把时间花在想上。

## 2. 视频（约 4 分钟，9 镜头）

1. **0:00–0:15 痛点**（口播）：一组数据拟合、算不确定度、修约、画图，几小时就没了，一步错全盘错。
2. **0:15–0:25 时代**（口播）：AI 应该把人从重复劳动里解放出来。
3. **0:25–0:55 免费 AI 翻车**：跑 `python demo/compare.py`，念出 15 位小数、±0.5 拍脑袋、不可复现。
4. **0:55–1:15 受约束方案**：切到受约束输出，讲白名单 / 强制规范 / 可溯源。
5. **1:15–1:55 一条命令**：跑 `python examples/run_examples.py`，三个实验一次跑完。
6. **1:55–2:35 自动识别**：跑 `--auto ... --hint 弹簧振子`，讲自动识别与映射。
7. **2:35–3:15 全流程管线**：跑 `-e youngs_modulus_raw --data-file ...`，讲拟合→直径→传播→误差预算。
8. **3:15–3:45 对比与可复现**：一个数 vs 一份报告，run_id + 重放一致。
9. **3:45–4:00 收尾**：约束 = 可信度；把时间花在想上。

字幕：`docs/字幕.srt`（9 段，可导入剪映/Pr）。

## 3. 风格统一（PPT 与视频是两种展示，但要是同一个作品）

- 同一主色 / 强调色 / 字体 / 页脚。
- 同一组数字与术语（两边都写 `9.85 ± 0.04 Ω`）。
- 同一句主张（结尾）。
- 视频片头 = PPT 封面同款；片尾 = PPT 结语同款。
- 互补：视频看「跑起来」，PPT 讲「为什么」。

## 4. 关键数字（两边必须一致）

- 伏安法：`R = 9.85 ± 0.04 Ω（k=2）`，r = 0.99999
- 弹簧振子：`k = 8.0 ± 1.8 N/m（k=2）`
- 杨氏模量：`E = (1.23 ± 0.20)×10^11 Pa（k=2）`，误差主要来自 b（98.6%）
- 免费 AI 对照：`9.848571428571425 Ω`（15 位）、±0.5 拍脑袋
- 作品规模：12 个实验 + 1 条全流程管线
