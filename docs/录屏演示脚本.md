# 录屏演示脚本：裸 LLM vs 受约束 Agent

> 目标：用 3 分钟证明「约束本身就是可信度的来源」。
> 总时长建议：3′00″ ~ 3′30″。所有数字来自 phyxexp 真实运行结果，直接念即可。

---

## 0. 录制前准备（1 分钟）

1. 环境就绪（已装好依赖）：
   ```bash
   pip install -r requirements.txt
   ```
2. 打开一个终端，进入项目根目录：
   ```bash
   cd phyxexp
   python demo/compare.py            # 伏安法（默认）
   python demo/compare.py "弹簧振子"  # 弹簧振子
   ```
3. 提前生成两张关键图，稍后切图展示：
   - `demo/out/伏安法-拟合.png`
   - `demo/out/伏安法-残差.png`
4. 把终端字号调大（建议 14~16pt），便于录屏看清。

---

## 1. 分镜脚本

### 镜头 1 · 痛点开场（15″）
- **画面**：录屏切到一张「AI 数据分析三大病」的字卡，或直接口播。
- **台词**：
  「现在的大模型做数据分析，最大的问题就三个字——**会编数**。
  它给你一个数，但说不清不确定度；你问它结论能不能复现，它答不上来；
  你问它残差合理不合理，它没有做任何物理一致性检查。」
- **字幕**：编数字 · 不可复现 · 缺物理检查

### 镜头 2 · 抛任务（10″）
- **画面**：终端里输入同一句话（作为「任务」）。
- **台词**：
  「同一句话，我同时喂给**裸大模型**和**受约束 Agent**：
  『伏安法测电阻，I 从 0.10 到 0.60 A，V 是这些值，求电阻。』」
- **字幕**：同一个任务，两种回答

### 镜头 3 · 裸 LLM 现场翻车（35″）
- **画面**：终端显示裸 LLM 的回答（`bare_llm.py` 输出）。
- **台词**：
  「看裸 LLM：它张口就来——**R ≈ 10.0 Ω，误差约 ±0.5 Ω**。
  但注意三件事：第一，这个 ±0.5 是**拍脑袋拍的**，没有任何计算过程；
  第二，**没有 R²，没有残差图**；第三，**不可复现**——你让它再算一遍，
  它可能给你另一个数。」
- **字幕**：点估计 · 无不确定度 · 无 R²/残差 · 不可复现
- **备注**：屏幕上把裸 LLM 的四个问题用红框/红字标出。

### 镜头 4 · 受约束 Agent 的约束长啥样（40″）
- **画面**：终端显示 Agent 的 plan（结构化 JSON）。
- **台词**：
  「再看受约束 Agent。它被锁进一个**白名单工具链**里：
  大模型只被允许做两件事——**选工具、填参数**，它**不能自己写代码、不能心算**。
  计算只能交给审查过的工具 `ohms_law_resistance`，跑最小二乘拟合。」
- **字幕**：LLM 只选工具+填参，绝不碰计算
- **画面**：高亮 plan 里的 `"tool": "ohms_law_resistance"` 和数据字段。

### 镜头 5 · 有不确定度、有 R² 的结论（30″）
- **画面**：终端显示 Agent 结论。
- **台词**：
  「结果是 **R = 9.849 ± 0.020 Ω**，这是实打实从拟合公式算出来的标准不确定度；
  相关系数 r = 0.99999，**R² = 0.99998**；
  扩展不确定度（k=2）就是 9.85 ± 0.04 Ω。
  对比一下：裸 LLM 说 10.0 ± 0.5，**不确定度虚高了 25 倍，还是编的**。」
- **字幕**：R = (9.849 ± 0.020) Ω，r=0.99999，R²=0.99998

### 镜头 6 · 残差图（20″）
- **画面**：切到 `demo/out/伏安法-残差.png`。
- **台词**：
  「更关键的是**残差图**：残差围绕零随机分布、没有趋势——说明模型是对的，
  没有系统误差。裸 LLM 拿不出这张图，因为它根本没算。」
- **字幕**：残差随机分布、无趋势 → 物理一致

### 镜头 7 · 可复现 + 可溯源（20″）
- **画面**：终端高亮 `run_id`、`输入哈希`、`重放结果一致: 是`。
- **台词**：
  「每次运行都有一个 run_id 和输入哈希，**重放结果逐位一致**。
  你的结论可以回到工具、回到公式、回到原始数据去核对——
  这就是**可复现**，这也是裸 LLM 给不了的。」
- **字幕**：run_id + 输入哈希 + 重放一致 = 可复现

### 镜头 8 · 一句话收尾（10″）
- **画面**：回到字卡「约束 = 可信度」。
- **台词**：
  「我们不是让大模型更会算数，而是**不让它算数**。
  把计算锁进受约束的工具链，**约束本身就是可信度的来源**。这就是 phyxexp。」
- **字幕**：phyxexp · 受约束的实验数据处理 Agent

## 2. 关键数据备忘（真实运行结果，供字幕/讲解引用）

| 项 | 裸 LLM（模拟） | 受约束 Agent（真实） |
|---|---|---|
| 伏安法 R | ≈ 10.0 Ω | 9.849 ± 0.020 Ω（k=2：±0.04） |
| 不确定度 | ±0.5 Ω（拍脑袋） | ±0.020 Ω（公式算出） |
| r / R² | 无 | 0.99999 / 0.99998 |
| 残差图 | 无 | 有（随机、无趋势） |
| 截距检查 | 无 | b=0.005 V，占比 0.09%，通过 |
| 可复现 | 否 | 是（run_id + 输入哈希 + 重放一致） |

弹簧振子（第二例，可选录制）：
- Agent：**k = 9.788 ± 0.005 N/m**，r ≈ 1.0000，截距 ≈ 0，通过一致性检查。
- 裸 LLM：k ≈ 9.8 N/m ± 0.3 N/m（编的）。

## 3. 诚实声明（答辩时会被问，务必主动讲）

1. 演示里的「裸 LLM」是**确定性脚本模拟**（`demo/bare_llm.py`），复现大模型
   的典型失败模式；接入真实大模型只会更不可控，这正是我们要约束它的原因。
2. phyxexp 引擎可**对接任意宿主大模型**（通过 `skills/SKILL.md` 的声明，
   大模型只被允许调用白名单工具，结论必须过 grounding 校验）。


## 4. 可配置 Skill 加卖点镜头（可选，答辩 / PPT 用）

### 镜头 9 · 可配置性（20″）
- **画面**：打开 config/experiments.json，高亮"linear_fit 这条是纯配置加的，没动一行 Python"。
- **台词**：
  「这套东西不是写死的一个实验。所有实验都声明在 config/experiments.json 里，
  想加别的实验——化学、生物、其他物理实验——只要在配置里加一条，
  再（需要时）登记一个公式工具，不改任何编排代码。」
- **字幕**：加实验 = 加一条配置，跨学科可扩展

### 镜头 10 · 宿主接入（15″）
- **画面**：打开 SKILL.md，高亮"硬约束"和 run.py 调用。
- **台词**：
  「它是真正的 Skill：把 SKILL.md 挂到 Claude Code 等宿主大模型里，
  大模型读到的是『你只能调 run.py，不能自己算』。SKILL.md 是给模型看的说明书，
  run.py 是唯一被允许的计算入口。」
- **字幕**：SKILL.md（给模型的说明书）+ run.py（唯一计算入口）
