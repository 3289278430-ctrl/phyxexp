# 公网部署指南（ChatGPT Actions 用）

ChatGPT 的 Actions 要求 **公网 HTTPS** 地址。下面三种方式从易到难：

## 方式一：ngrok（本地最快，演示够用）
```bash
python scripts/server.py --port 8000
# 另开一个终端
ngrok http 8000
```
拿到 `https://xxxx.ngrok-free.app`，把 `chatgpt/openapi.json` 的 `servers[0].url` 改成它。

## 方式二：Cloudflare Tunnel（免费、稳定）
```bash
cloudflared tunnel --url http://127.0.0.1:8000
```
得到 `https://xxx.trycloudflare.com`，同样填进 openapi.json。

## 方式三：云平台（长期）
把仓库部署到 Render / Railway / Fly.io 等，启动命令：
```bash
python scripts/server.py --host 0.0.0.0 --port $PORT
```
把平台给的 HTTPS 域名填进 `chatgpt/openapi.json`。

## 注意
- 服务是无状态的，不需要数据库。
- 只暴露 `/list` 与 `/run` 两个端点，且内部只走白名单工具——即使公网暴露，也**不能执行任意代码**。
- 生产环境建议加一层反向代理 + 简单鉴权（本项目默认不做，因为是演示）。
